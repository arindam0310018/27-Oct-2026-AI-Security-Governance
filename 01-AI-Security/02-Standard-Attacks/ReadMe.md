
# AI SECURITY #2:  Standard Attacks on AI Systems:-

| # | THREAT NAME | THREAT DETAILS |  
| --------- | --------- | --------- |
| 1. | POISONING | Manipulate training data or model parameters. |
| 2. | EVASION | Crafted inputs push the model into wrong outputs. |
| 3. | INFERENCE & INVERSION | Training data can be inferred from the model’s responses. |
| 4. | STEALING | The model is rebuilt through repeated queries. |
| 5. | INJECTION | Attacks on the input, and on how downstream systems handle the output. |
